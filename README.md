# Handwritten Character Recognition

## Objective

Develop a deep learning model capable of recognizing handwritten digits from images.

## Dataset

MNIST Handwritten Digits Dataset

* 60,000 training images
* 10,000 testing images
* Digits from 0 to 9

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Scikit-learn

## Model Architecture

* Convolutional Neural Network (CNN)
* Conv2D Layer
* MaxPooling Layer
* Flatten Layer
* Dense Layer
* Softmax Output Layer

## Data Preprocessing

* Normalized pixel values from 0-255 to 0-1
* Reshaped images to 28×28×1

## Model Performance

Test Accuracy: 98.74%

## Evaluation Metrics

Classification report generated for all digit classes (0-9).

## Conclusion

The CNN model successfully classified handwritten digits with an accuracy of 98.74%. The project demonstrates the effectiveness of deep learning techniques for image recognition tasks.
